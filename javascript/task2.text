🟠 Increment & Decrement Tasks
Task 11 — Post Increment
Predict the output before running the code:

let b = a++;

console.log(b); // 10
Write your expected output first, then run it.
Task 12 — Pre Increment
Predict the output:
let a = 10;

let b = ++a;

console.log(a); // 11
console.log(b); //11
Task 13 — Post Decrement
Predict:
let a = 20;

let b = a--;

console.log(a); // 19
console.log(b); // 20
Task 14 — Pre Decrement
Predict:

let b = --a;

console.log(b); // 19
